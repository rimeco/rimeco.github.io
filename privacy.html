Privacy Policy

GYB — Personal Gmail Backup · Last updated: 31 August 2026

Who this applies to

GYB ("the application") is a personal, single-user command-line application operated by Jean Leroy (jcleroy@gmail.com). It is not published, not distributed and not offered to third parties. The only account it is ever authorised against is the operator's own Google account.

What data is accessed

When authorised by the account owner, the application uses the Gmail API to read the messages, attachments and labels of that same account, together with the account's email address for identification purposes.

How the data is used

Message data is used for one purpose only: writing a local backup copy to a storage device owned by the operator. The data is not analysed, profiled, sold, shared, transferred to any third party, or used for advertising. No copy is uploaded to any server, and no data is transmitted anywhere other than between Google's API endpoints and the operator's own computer.

Where the data is stored

Backups are stored on a private local disk. Access is limited to the operator of the machine. The OAuth credentials issued by Google are stored in a local configuration file on that same machine.

Retention and deletion

Backup files are retained for as long as the operator wishes and can be deleted at any time by deleting the backup folder. Access can be revoked at any moment through Google Account → Third-party apps, which immediately invalidates the application's credentials.

Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
