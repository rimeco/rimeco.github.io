GYB — Personal Gmail Backup

A private, single-user application.

This page exists to support the OAuth consent screen of GYB, a personal installation of the open-source tool Got Your Back (GYB).

The application is run from the command line on a private computer by its owner, and is used for one purpose only: to download a local backup copy of the owner's own Gmail mailbox, so that messages remain available if access to the online account is ever lost.

The application is not distributed, not offered as a service, and has no users other than its owner.
